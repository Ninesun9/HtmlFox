# HtmlFox

Choose your preferred README language:

- **English**: [README.en.md](README.en.md)
- **简体中文**: [README.zh-CN.md](README.zh-CN.md)

HtmlFox is a native SwiftUI app for opening HTML files, previewing them as rendered documents, editing visible text directly in the preview, and exporting the result as HTML or PDF.

HtmlFox 是一款原生 SwiftUI 应用，可用于打开 HTML 文件、以渲染后的文档形式预览、直接在预览中编辑可见文本，并将结果导出为 HTML 或 PDF。
