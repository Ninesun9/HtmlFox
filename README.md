# HtmlFox

> A native, offline-first HTML reader, editor, and exporter for iPhone and iPad.
> 一款原生、离线优先的 HTML 阅读、编辑与导出工具，支持 iPhone 与 iPad。

---

HtmlFox opens `.html` / `.htm` / `.xhtml` files, renders them as documents, searches inside the page, switches between mobile and desktop preview widths, edits visible text directly in the preview or in a source editor, and exports the result as **HTML** or **PDF**. It is fully on-device — no data collection, no tracking, and no network calls of its own.

HtmlFox 可打开 `.html` / `.htm` / `.xhtml` 文件，渲染成文档、页内搜索、在移动端与桌面端预览宽度间切换、直接在预览或源码编辑器中修改文本，并导出为 **HTML** 或 **PDF**。完全在设备本地运行——不收集数据、不追踪、自身不发起网络请求。

- Platform / 平台: iOS 16+ (iPhone & iPad)
- Stack / 技术栈: SwiftUI · WebKit · StoreKit 2
